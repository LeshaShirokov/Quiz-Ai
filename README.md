# Quiz-Ai — конструктор квизов

Статический конструктор квизов на **HTML, CSS и чистом JavaScript** — без фреймворков, сборки и внешних зависимостей.
Создайте квиз, пройдите его сами или отправьте ссылку — квиз закодирован прямо в ссылке, сервер не нужен.

**Живая версия:** https://leshashirokov.github.io/Quiz-Ai/

## Возможности

- **Два режима** на одной странице: «Конструктор» и «Прохождение».
- **Четыре типа вопросов:**
  1. Выбор **одного** варианта ответа (radio).
  2. Выбор **нескольких** вариантов ответа (checkbox, несколько правильных; засчитывается только точное совпадение набора).
  3. **Число** — с необязательной погрешностью `±` (дробную часть можно писать через запятую или точку).
  4. **Слово без пробелов** — ответ сравнивается без пробелов по краям, по желанию без учёта регистра; можно указать альтернативные правильные слова; ввод с пробелом отклоняется с сообщением.
- **Конструктор:** название и описание квиза; добавление, редактирование, удаление и перемещение вопросов (вверх/вниз); у каждого вопроса — тип, текст, баллы и пояснение, которое показывается в разборе после ответа.
- **Проверка** квиза с понятными сообщениями на русском (минимум 2 варианта, хотя бы один правильный, ровно один правильный для «одного ответа», число для числового ответа, слово без пробелов и т. д.).
- **Автосохранение** черновика в `localStorage`.
- **Импорт / экспорт** квиза в JSON-файл (импортируемый файл проверяется по схеме) и кнопка «Загрузить пример» с квизом, где есть все четыре типа вопросов.
- **Прохождение:** один вопрос на экране, прогресс-бар, «Назад» / «Далее», проверка ввода, экран результатов с баллами и процентом, разбор каждого вопроса (ваш ответ, правильный ответ, пояснение), «Пройти заново», «Вернуться в конструктор».
- **«Скопировать ссылку»** — квиз кодируется в адрес (`index.html#quiz=…`, base64url от UTF-8 JSON). При открытии такой ссылки сразу запускается прохождение. Для очень длинных ссылок показывается предупреждение.
- **Безопасность:** весь пользовательский текст выводится через `textContent`, без `innerHTML` — в том числе из импортированного JSON и ссылок.
- **Дизайн:** адаптивная вёрстка, светлая и тёмная тема (по умолчанию — как в системе, выбор сохраняется), доступность: подписи полей, видимый фокус, управление с клавиатуры, `aria-live` для сообщений проверки.

## Как пользоваться

1. Откройте «Конструктор», введите название квиза.
2. Выберите тип вопроса и нажмите «+ Добавить вопрос». Заполните текст, баллы, варианты/ответ и (по желанию) пояснение.
3. Нажмите «Пройти квиз», чтобы проверить его, или «Скопировать ссылку», чтобы отправить другим.
4. «Экспорт JSON» сохраняет квиз в файл, «Импорт JSON» загружает его обратно.

## Формат JSON

```json
{
  "format": "quiz-ai",
  "version": 1,
  "title": "Название квиза",
  "description": "Описание (необязательно)",
  "questions": [
    {
      "type": "single",
      "text": "Столица Австралии?",
      "points": 1,
      "explanation": "Пояснение (необязательно)",
      "options": [
        { "text": "Сидней", "correct": false },
        { "text": "Канберра", "correct": true }
      ]
    },
    {
      "type": "multiple",
      "text": "Какие числа простые?",
      "points": 2,
      "options": [
        { "text": "2", "correct": true },
        { "text": "4", "correct": false },
        { "text": "7", "correct": true }
      ]
    },
    { "type": "number", "text": "Чему равно π?", "points": 1, "answer": 3.14, "tolerance": 0.01 },
    { "type": "word", "text": "Самая большая планета?", "points": 1, "words": ["Юпитер", "Jupiter"], "caseSensitive": false }
  ]
}
```

| Поле | Тип | Описание |
|---|---|---|
| `type` | `single` \| `multiple` \| `number` \| `word` | Тип вопроса |
| `text` | строка | Текст вопроса |
| `points` | число > 0 | Баллы за правильный ответ (по умолчанию 1) |
| `explanation` | строка | Необязательное пояснение для разбора |
| `options` | массив `{text, correct}` | Варианты для `single` / `multiple` |
| `answer`, `tolerance` | числа | Правильный ответ и допустимая погрешность для `number` |
| `words`, `caseSensitive` | массив строк, boolean | Правильное слово и альтернативы для `word`; учитывать ли регистр |

## Локальный запуск

Достаточно открыть `index.html` в браузере — всё работает и с `file://`.

Или запустите простой сервер:

```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```
